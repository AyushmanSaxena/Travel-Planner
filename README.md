# ✈️ AI Travel Planner Agent

An AI-powered conversational Travel Planner Agent that helps travellers create personalized and budget-friendly travel plans through natural conversation.
The project uses IBM Bob for the web interface, IBM watsonx Assistant for conversational interaction, and IBM Granite for intelligent itinerary generation and travel recommendations.

# 📌 Project Overview

Planning a trip can be complicated because travellers need to consider destinations, budgets, duration, transportation, accommodation, sightseeing, food, and personal preferences.
The AI Travel Planner Agent simplifies this process by allowing users to communicate their requirements naturally. The agent understands the traveller's goals and constraints and generates a personalized travel plan.
The agent can then continue the conversation to understand:
📍 Destination
📅 Travel dates or duration
🚗 Starting location
💰 Budget
👥 Number of travellers
🏛️ Places of interest
🍴 Food preferences
🏨 Accommodation preferences
🚆 Transportation preferences
Based on these requirements, the agent generates a suitable itinerary.

# 🚀 Key Features

💬 Conversational Travel Planning
Users can describe their travel plans naturally instead of filling out complicated forms.
🗺️ Personalized Itinerary
Generates day-wise travel plans according to destination, duration, interests, and preferences.
💰 Budget-Aware Planning
Considers the traveller's budget while creating recommendations.
🏨 Accommodation Suggestions
Provides accommodation recommendations based on traveller preferences and budget.
🚆 Transportation Suggestion
Suggests suitable transportation options for the planned trip.
🏛️ Attractions & Activities
Recommends sightseeing locations and activities based on traveller interests.
🍴 Food Recommendations
Suggests local food experiences and dining options.
🔄 Dynamic Re-planning
The traveller can change requirements during the conversation and request an updated itinerary.
🧠 Context-Aware Conversation
The assistant maintains the context of the ongoing travel-planning conversation.
🌐 Interactive Web Interface
IBM Bob is used to create the user-facing website for interacting with the Travel Planner Agent.
